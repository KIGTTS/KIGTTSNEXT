# KIGTTS NEXT

KIGTTS 的 Android 原生重构续作，使用 Kotlin、Jetpack Compose 和 Material 3 Expressive。应用以提供的参考图为基础，实现同一主页的字幕、聆听和快捷文本状态。仓库保持私有；主程序与通用 SDK 采用 MIT，原版移植引擎插件保留 GPLv3（见各插件 LICENSE/NOTICE）。

Expressive 组件与动效固定使用官方 material3:1.5.0-alpha01；此依赖属于预览版本。

## 当前功能

- 原始横版 Logo、胶囊按钮、原生 Expressive 按压形变；按钮组用固定 6 dp 弹簧伸展，相邻按钮与卡片联动圆角，长按钮不会按宽度比例过度挤压邻居。主界面字幕、聆听、快捷文本面板和短语卡片外圆角统一限制为 4–20 dp，圆角动效不会越过范围。
- 快捷文本入口可点击或连续上滑展开为可调整高度的底部面板，按钮变为拖动横条；单行横向列表，增高后以淡入及位移切换纵向网格，保留两种布局的滚动位置。纵向手势只滚动内容，面板高度通过顶部横条调整。折叠按钮或通过横条拖到底部收起均保留上次展开高度，重新打开后恢复，重启应用也保留高度。底色独立淡入淡出，两侧插件槽保持固定身份，扩展按钮出现或实时修改不会中断连续上滑。
- 快捷文本编辑时面板占满应用可用区域，临时收起顶栏、聆听和大字幕，完成/返回恢复原布局与高度。条目与分组支持手柄或长按拖动排序、位置过渡及边缘自动滚动；排序固定视口，避免首项变化导致滚动跳动。拖动条目与分组抬升 8 dp 阴影；分组只允许水平拖动并转为实色底，左侧始终显示组图标，右侧显示手柄，活动组手柄变为铅笔，再次点击可修改名称和图标。条目拖至窗格左右边缘会淡入箭头，停留 550 ms 后转移到相邻组并切换，当前拖动手势保持；每次进入边缘只切换一次。分组切换有左右滑动过渡，普通网格和编辑网格支持左右滑动切换，单行模式保留横向条目滚动。编辑条目默认保持 64 dp，手柄与文字同行；右上角 32 dp 圆形删除键须二次确认，末尾用低调的图标文字入口添加条目。新增分组可选择 12 个原生图标，图标随分组顺序持久化并显示于普通/编辑 Tab；单击条目通过详情弹窗修改文本、辅助说明和所属分组。条目稳定 ID、空分组和两种顺序均持久化，兼容旧数据，重复文字可独立操作。
- 底部分组 Tab 和固定插件入口共用原生 FilterChip、MD3e 圆角弹簧与邻居按压联动，外侧端点呈圆形；分组数量随用户添加变化，分类栏独立横向滚动。
- 输入时顶栏和聆听字幕收缩、渐隐，快捷文本区向下滑出，大字幕同步伸展占满键盘上方空间；系统栏与键盘 Insets 只消费一次。退出时带动效恢复原先开关、高度与滚动位置，识别任务保持运行。
- 大字幕卡片的非按钮区域均可点击进入输入；长按进入强制全屏，键盘隐藏后仍保持全屏，返回后恢复面板。发送快捷文本、程序更新及清空字幕采用原生 MD3e 淡入淡出与轻微位移；输入中的程序更新使用原编辑框淡入，保留焦点、选区与 IME，普通键盘输入不重复触发替换动效。
- 大字幕根据宽高自动适配字号，用户设置为字号上限，自动缩小下限为 24 sp（手动选择更小字号仍尊重设置）；超过可读下限后滚动查看。显示与输入均保留完整文本，内容缩短或空间扩大后恢复字号。快捷文本收起时底部区域为 72 dp，入口按钮高 48 dp；展开后两侧保留 32 dp 小圆按钮。
- 大字幕字号按单个汉字字宽占当前窗口宽度的百分比保存（3–25%），默认在 393 dp 屏幕上约为 38 sp。屏幕宽度、横竖屏或系统字体缩放变化时按原生字体换算还原同一比例；双指缩放和行内滑条修改同一偏好，长文本自适应不覆盖该值，重启后恢复。聆听字号栏使用 24 dp 原生滑块与 8 dp 轨道，固定 32 dp 操作区，文字只在独立视口滚动。
- 输入底部中央是相对光标拖动条，按字素边界移动真实选区；字号通过双指缩放或缩放按钮打开的行内滑条调整，临时替换左侧按钮区，完成或返回后恢复。
- 大字幕支持上下翻转，输入期间临时恢复正向。大字幕和聆听字幕各自支持双指缩放。
- 聆听上面板由字幕插件注册“开始聆听 / 关闭聆听”与面板操作，可拖动调整高度，默认隐藏；识别任务结束后仍可关闭面板。顶部空间不足时先缩成 40 dp 单行并移除按钮区，再隐藏，空间恢复后还原用户高度与开启状态。面板不设标题栏，缩放键位于右下角，两张字幕卡片之间的手柄垂直居中。
- 快捷文本长按由独立语音输入插件注册，默认关闭；关闭后长按无行为，开启后调用占位入口，不触发聆听。两种能力均与 ASR 引擎分离。
- 画板与名片使用标准 MD 二级页面与统一页面栈，保留画板左侧、名片右侧的进入及完整返回过渡；抽屉菜单从右侧展开，仅由右上角按钮打开，可向右滑动或点击空白关闭，移除快捷文本入口。返回先完整关闭抽屉，预测返回提交、关闭期间再次返回及首次开启动画均不会停在半开或关闭下层面板。
- 设置统一为二级分类页，主题与颜色、显示与形状、触感反馈、插件管理进入三级页；保留上一层背景，支持完整进入、逐层返回、预测性返回及取消恢复。恢复默认仅重置对应分类。
- 所有多级页面使用原生空间动效：新页以 320 ms FastOutSlowIn 缓动滑入，避免弹簧越界；父页轻微位移、缩小并遮暗。返回时保留退出页直到完全离屏，父页同步恢复，返回与预测动效沿用 MD3e 空间曲线。预测返回提交从当前位移/缩放/圆角姿态继续退场，取消完整复原；进度绑定页面身份，避免传给新父页。快速多层返回、退场中重开、重复目的地均保持状态和过渡，最后一页退出完成前不让返回误关主页控件。切换页面时清除旧焦点、收起输入法，保留父页草稿与滚动位置。
- 全局按钮、菜单、Tab、切换、确认弹窗与插件操作共用系统触感反馈；成功点击触发一次，滚动、取消按压和禁用按钮不触发点击震动。快捷文本、聆听与输入光标横条按下立即轻振并弹性变长、变粗，松手或取消恢复；轻触不调整高度或光标，超过原生触摸阈值后才拖动。面板拖动每跨过 32 dp 区间及结束提供原生触感；光标条每 12 dp 移动一个字素，实际选区变化才发移动触感，到达文本边界不重复震动；取消拖动不发结束反馈。折叠时快捷文本胶囊保留原生点击/长按反馈。设置可关闭触感，包含原生长按反馈，开关本地保存并遵循系统触感设置。
- 画板使用原生 Toolbars，保留笔、橡皮擦、颜色、保存、清空五项工具。再次点击所选工具打开大小/类型菜单，支持圆笔、钢笔、荧光笔及局部/整笔擦除。
- 色板当前色固定在左侧，与横向滚动的预设色用分隔线隔开；点击当前色打开支持 HSV/HEX 的取色器。
- 触控笔支持压力变化、历史采样点、侧键临时擦除及橡皮端；按住 E 键也可临时擦除。松开恢复原工具，系统取消输入时回滚该笔触。PNG 保存保持画布比例、压感笔宽与擦除效果。
- 外观支持跟随系统（默认）、亮色、深色，设置本地保存，系统栏图标同步。两种模式均使用原生 MD3e 颜色角色：基准色 #00696E、Android 12+ 壁纸取色开关、默认/中/高三档对比度；圆角为小 4 / 中 14 / 大 24 dp 三档，默认大，旧连续设置就近迁移。更暗深色仅在深色模式下应用。亮色主页的小按钮、Tab 与插件入口在默认对比度下使用原生中档颜色角色，提高控件与表面的区分和文字可读性；页面配色与三档设置保持各自原值，深色/中高档沿用对应角色。页面与小按钮颜色切换均以 450 ms 渐变过渡。
- 插件可注册四角按钮、菜单项、抽屉条目、声明式页面与规范手势入口。右侧入口从右向左增加，超量收进下箭头菜单，图标文字按钮在空间不足时压缩为图标。Tab 首尾插件入口固定在分类滚动区两侧。调试插件按区域配置 0–20 个入口，默认全部关闭，继承宿主区域样式。入口数量、标签、图标和图标/文字样式实时变化使用淡入淡出、轻微缩放与尺寸过渡；退出快照隐藏无障碍入口和菜单，点击按当前 ID 路由，已撤销动作不会执行。
- 面板拖动高度在控件内跟手、松手后更新全局状态；复用字幕段落测量，按钮宽度动画在布局测量阶段读取，减少拖动过程的全局重组和重复计算。
- 快捷文本条目拾起时同帧切换为不透明浮层，松手后以原生空间弹簧落回目标槽位，再交回列表；海拔与缩放随落位恢复，避免闪烁与瞬移。页面层不使用固定整页阴影，导航绘制限制在系统栏内的内容视口。右侧抽屉标题区使用横版 LOGO。

系统 TTS 与 SenseVoice 已拆成独立 .kigplugin，通过插件管理安装、启停、选择和卸载。主 APK 不包含语音引擎或其依赖；未安装引擎时只显示提示。识别支持完整录音和分段流式，麦克风由宿主在用户授权后访问。模型、网络和外置文件资源统一保存在 appdata/Kigtts/plugin/plugindata/<pluginId>/。主应用与两个独立插件已通过 Android 16 真机测试：TTS 合成/播放、识别模型导入、完整录音/分段流式和取消后重用。现场麦克风表现与长期识别精度仍需使用验证。

## 模块

- app：原生 UI、状态、持久化、插件宿主；主页和画板按职责拆分文件。
- plugin-api：不依赖 Android/Compose 的引擎、UI 扩展与页面协议。
- material-color：固定版本的官方 Material Color Utilities Java 源码，保留 Apache-2.0 LICENSE 与 NOTICE。
- plugin-runtime / plugin-android-api：专用包校验、独立进程、PCM IPC 与插件数据环境。
- engine-plugins/system-tts、engine-plugins/sensevoice-asr：独立构建、安装的语音插件。
- plugins/placeholder-tts、plugins/placeholder-asr：仅用于测试，生产 APK 不包含。
- plugins/listening-panel：通过宿主命令驱动聆听面板，与 ASR 引擎分离。
- plugins/voice-input：可关闭的长按语音输入入口，与字幕插件分离。
- plugins/debug-ui：各扩展区域的按钮数量、图标/文字样式与菜单/弹窗/页面调试。
- ARTS：从原工程迁移的品牌素材。

内置功能 UI 与外部引擎均遵循 [插件 API v2](docs/plugin-api.md)。专用包、安装使用、签名、资源目录和隔离限制见 [插件包说明](docs/plugin-packages.md)；外部代码目前只支持可信来源，独立进程并非权限沙箱。
