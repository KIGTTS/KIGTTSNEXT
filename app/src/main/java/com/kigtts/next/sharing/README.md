# 分享与面对面

分享照片、名片或快捷文本时统一进入 `SharingCoordinator`。首次分享会询问是否使用云端互传；启用后由云分享插件提供二维码、NFC 和附近互传。KIGTTS 内的接收页面使用原生控件，外部浏览器可通过公开分享链接领取。

选择仅使用系统分享、关闭云分享插件或无法使用云分享时，可通过系统分享发送照片、快捷文本包和个人主页 PDF。导出文件由 FileProvider 临时授权给接收应用。旧版本地分享服务已移除，已接收的名片和照片不受影响。

设置中的「面对面接收」独立控制接收邀请，不依赖发送面板是否打开。发送面板关闭不主动撤销已开始的云端会话；用户可通过分享通知提前结束。接收方是否需要发送者确认取决于当前云插件和服务的协议版本。
