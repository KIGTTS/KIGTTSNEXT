# 分享与面对面

分享照片、名片和快捷文本统一进入 `SharingCoordinator`，当前通过 Android 系统分享发出文件。照片与快捷文本继续使用对应的文件格式，个人主页可选 PDF、MHTML 和 PNG 长图。云分享、面对面接收与主动 NFC 分享暂时停用，已安装的插件与收藏保留。

MHTML 在本地打包网页、图片和带类型的名片资料；浏览器打开时可离线查看磁贴、图片和联系二维码。KIGTTS 导入时只解析本应用的名片资料和受支持的图片分段，不执行文件中的 HTML 或脚本。通过文件打开或收藏夹导入后直接添加到扩列收藏夹；同一身份更新原收藏。

长图不显示图片磁贴预览，按链接汇总底部二维码，并附四级灰阶还原码。还原码描述公开资料和封面位置；启用“长图嵌入源数据”还会写入私有 PNG 数据块，可恢复图片磁贴。该选项默认关闭，部分聊天软件会重新编码图片，裁剪底部或强压缩可能让还原码不可读。

选择仅使用系统分享、关闭云分享插件或无法使用云分享时，可通过系统分享发送照片、快捷文本包和个人主页 PDF。导出文件由 FileProvider 临时授权给接收应用。旧版本地分享服务已移除，已接收的名片和照片不受影响。

设置中的「面对面接收」独立控制接收邀请，不依赖发送面板是否打开。发送面板关闭不主动撤销已开始的云端会话；用户可通过分享通知提前结束。接收方是否需要发送者确认取决于当前云插件和服务的协议版本。
