# 面对面返图与附近互传

相册预览中的照片上滑，或从照片/多选操作打开「分享」。顶部显示自己的名片、单张照片或照片堆叠；照片可选择原图、拍立得成片或两种。打开即开始面对面发现，不等待所有照片渲染。下方为横向滚动的发现栏：

- 分享：进入系统分享，支持多张图片；独立导出副本不会因结束面对面会话失效，实况照片沿用原导出路径。
- Wi-Fi 互传：进入扫码领取与临时热点连接。
- 附近头像：直接点选发送，实际传输前由接收方确认。

- 扫码领取：同一 Wi-Fi 可直接扫码；否则创建 LocalOnlyHotspot，先连接 Wi-Fi，再扫码进入浏览器领取页。结束分享会关闭服务器并撤销本次入口。
- 附近互传：接收方打开「面对面接收」，发送方点选对方。接收方确认后保存到「面对面接收」相册，可以为本次会话开启自动接收。后续选择新照片可继续发送。
- 发送者名片：接收照片保留发送时的昵称、简介、头像和联系方式；从照片菜单/页面入口查看。个人名片由设置页管理，背景和贴纸复用相册编辑器。

## 资源与生命周期

`FacePhotoSession` 持有随机入口、本地 HTTP 服务、声明过的文件和接收许可。服务器只接受本机/私有网络连接，不提供任意路径读取。每次接收有文件大小、类型、SHA-256 和数量限制，临时写入完成才导入；重复提交不会重复建立相册卡片。用户确认与本次会话自动接收分别处理，分享通知可以结束会话。

`FaceShareController` 协调显式页面、临时文件与连接；创建和关闭采用独立资源所有权，旧会话清理不影响新会话。离开面对面页面停止 NSD/BLE 搜索，已建立的传输和本地领取页可以保留到结束分享。

“附近互传”和“面对面接收”都会广播并搜索，双方都进入“附近互传”也能互相发现；接收仍需确认。同一 Wi-Fi 优先使用 NSD，并以 IPv4 局域网广播作为备用。注册、浏览与解析失败自动重试，旧 NSD 栈串行解析；Wi-Fi 变化后重建发现，页面关闭或进入后台时释放组播锁、监听器与 UDP 套接字。广播不进行网段逐地址扫描，消息长度、地址、数量与响应频率均有限制。

发现公布的 peerToken 与浏览器领取 token 分开：peerToken 仅能查看公开名片和发起需确认的传输，不能打开领取页或下载发送方准备的照片。旧版接收端的 NSD 类型与传输路径保持兼容。

BLE 只交换连接描述，Wi-Fi Direct 用于无路由器时的照片传输。Android 的系统授权/配对提示仍由系统显示；权限拒绝后可以尝试同一 Wi-Fi。路由器若启用 AP/客户端隔离，NSD 和广播都不能跨越隔离，需要换网络或用临时热点扫码。Wi-Fi Aware 和 NFC 配对属于后续增强。

BLE 描述包含有限数量的私有局域网地址，不含头像大数据。`FacePeerResolver` 优先通过这些地址或 NSD/UDP 的地址读取 `hello`，核验会话 ID 后补齐昵称、头像和头像框，失败后限速重试。稀疏发现更新不会抹除已解析资料，新 token/端口不沿用旧地址。发送前重新核验端点，避免无须直连时误走 Wi-Fi Direct。

Wi-Fi Direct 只公布本机 MAC，不把所连组主冒充为本机；双方开启接收时，仅撤销当前会话创建的本机组再加入对方。连接完成广播需匹配所选对方，取消时停止协商；失败提示使用设置中的接收开关及同 Wi-Fi/扫码操作。

## 验证范围

`FacePhotoSessionTest` 通过真实 loopback TCP 套接字验证链接隔离、浏览器 ZIP 选择、接收同意、完整性、幂等与会话结束。`PersonalCardsTest` 与 `PersonalCardsUiTest` 覆盖名片背景/贴纸导出、16:9 接收、联系方式、编辑保存和翻页。社交平台入口使用固定版本的 Remix Icon 本地矢量，见 `docs/remix-social-icons.json`。

浏览器模板已检查手机和桌面布局、选图同步、箭头切图与控制台。上述自动化与浏览器检查不代表无线硬件验收；LocalOnlyHotspot、BLE 广播/连接、Wi-Fi Direct 双机协商和各厂商后台限制仍需两台真实设备验证。

`FaceNsdDiscoveryTest` 覆盖重试、串行队列、超时、旧回调隔离、网络变化、组播锁释放和 IPv4 选择；`FaceLanBeaconTest` 使用真实 loopback UDP/TCP 验证双方发现、端点传输、接收确认、关闭和消息边界。`FaceUnifiedShareUiTest` 与 `FaceSystemShareTest` 覆盖统一面板、名片/照片替换、发现栏横向滚动、多图系统分享及文件授权。无线硬件与真实路由器仍需另行双机验收。
