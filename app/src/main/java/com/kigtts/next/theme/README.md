# 外观与背景

`ThemeSettings` 保存主题模式、配色来源、背景、字体及背景取色提醒。壁纸、背景图与自定义配色互斥；背景颜色单独保存，切回自定义时恢复原有颜色。

`AppearanceBackdrop` 是页面通用背景层，`PageScaffold.backgroundSettings` 可按页面接入。`AppearanceBackgrounds` 按资源标识共享已解码图片，横竖屏复用同一实例；布局变化只改变裁切，不重新解码。导入时先处理好图片和缓存，再更新当前背景。

背景裁剪以方形为母版，透明十字遮罩显示横竖屏的中心区域；裁剪页仅改变预览和最终背景副本。`BackgroundCrop` 用归一化中心和缩放保存位置，转屏时保留。

快捷文本抽屉使用 `DrawerBackdrop`。`BackgroundBlurCache` 在 IO 线程预生成低分辨率可分离高斯模糊并写入版本化磁盘缓存；绘制时与主背景共享窗口坐标。拖动抽屉只绘制缓存图片，不截图或逐帧模糊。

字体通过独立页面管理，`InstalledFonts` 保存本地字体名称，`FontCatalog` 读取字体源与 SVG 预览，`AppearanceFont` 统一字高。

外观缩略图读取 `HomePreviewGeometry` 中实际主界面的几何区域并等比绘制；省略文字、图标、媒体和聆听字幕区，不保存包含用户内容的截图。

回归覆盖裁剪边界、原图保留、高斯对称性与缓存复用、转屏图片实例、配色持久化、不再提醒、原生裁剪确认、字体入口及主界面测量预览。物理屏幕转向的帧连续性仍需设备检查。
