# KIGTTS

[简体中文](../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

![KIGTTS](../ARTS/Promotion/github-cover.webp)

A pocket dialogue box for Kigurumi players and friends. When you're in costume and want to say hi, ask for a photo, or swap socials, just hold up your phone.

- Put a big caption on screen or tap a phrase you saved earlier
- Read what you type aloud or see what others say as captions
- Take a photo, draw a quick note, or swap profile cards
- Pick a look, try new voices and stickers, or make your own tools with the plugin editor

KIGTTS 1.0.0 is in preparation. The upgrade guide picks up where you left off and skips the permissions and phrase presets. Older backups can be opened from **Backup & Restore**.
