# KIGTTS

[简体中文](../README.md) · [English](README.en.md) · [한국어](README.ko.md)

![KIGTTS](../ARTS/Promotion/github-cover.webp)

着ぐるみで遊ぶ人と仲間たちの、持ち歩けるふきだしです。「こんにちは」「一緒に撮ってもいい？」。そんなひと言を、スマホを見せて伝えられます。

- 大きな字幕を表示したり、よく使うフレーズをワンタップで出したり
- 入力した文を読み上げたり、聞こえた言葉を字幕で読んだり
- 写真を撮ったり、手書きで話したり、プロフィールカードを交換したり
- テーマや声、ステッカーを替えて、自分用のプラグインも作れます

KIGTTS 1.0.0 は準備中です。旧版から更新すると、権限とフレーズプリセットの案内は省略されます。旧版のバックアップも「バックアップと復元」から開けます。
