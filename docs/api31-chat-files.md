# API31：聊天文件

新增`ChatFile`，包含调用插件作用域的`PluginResource`、原文件名、字节数、MIME与可选`openAction`。
`ChatMessage.files`展示用户与助手的文件；`PageBlock.Chat.fileAction/draftFiles/removeFileAction`提供独立文件入口与草稿。
保留旧构造器、默认参数桥和`copy`入口，旧聊天包无需重编译。

文件卡片使用主题色，支持横向滚动、原名与大小以及移除草稿。仅文件也可发送/入队，纯文件的助手消息保留在时间线中。点击附件调用插件提供的操作；AI助手使用`ExportResource`进入系统保存流程。

用户从系统文件选择器导入`imports/`时原子复制原字节，保留运行中的插件实例；模型、运行资源等原有导入保留重载流程。文件内容不经Binder传输，仅传递作用域引用。

AI助手0.9.25最多8个文件、单文件64MB、总计128MB。文本按字节分段读取并保留UTF-8边界；二进制不伪装为文本。复制、快捷文本项目资源和跨插件导入沿用各自作用域、容量与审核规则。

验证覆盖SDK往返/旧JSON/copy兼容、文件UI与时间线、原始二进制复制/路径逃逸/覆盖拒绝、中文与Emoji分页、MIDI/PLY结构信息、草稿与队列持久化和接收方pending回执。实机功能验收由用户完成。
