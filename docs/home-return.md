# 主界面返回习惯

第一次在主界面按返回键时，弹窗让用户选择按一次或按两次返回键退出。默认选中两次；确认后记忆选择，取消则下次再询问。在「设置 → 操作反馈 → 返回操作」可以调整「二次返回退出」，设置搜索也能找到它。

选择两次时，第一次提示「再按一次返回键退出」，两秒内再次返回将任务移到后台，保留进程和最近任务。进入子页面、输入、快捷文本编辑、面板或弹窗时优先处理当前界面，回到首页或切入后台后重置计时。

`HomeExitTest`、`HomeExitUiTest` 覆盖首次询问、取消不保存、单次与双次退出、持久化、计时过期、设置入口和子页面返回。键盘关闭则在系统开始隐藏 IME 时同步恢复字幕布局，避免键盘先关完才退出输入全屏；事件序列由 `InputModeLifecycleTest` 覆盖，实际系统键盘动画仍需设备触控验收。
