# HTML 文件与编辑器

页面卡片的“创建页面文件 / 管理页面文件”打开独立项目文件页。字幕、缩略标题与条目草稿保留，返回后可保存条目。已有宿主 HTML 沿用媒体 ID/项目目录；插件 HTML 复制为宿主项目，不改写插件资源。远程 HTTPS 页面可直接选用，本地页面使用独立项目。

## 文件管理

项目支持多级目录和可横向滚动的面包屑，直接返回根目录或任意上级。正文操作栏提供导入与新建文件/文件夹，顶栏提供预览与导入整个目录。导入保留文件名/结构，同名自动编号，失败回滚本批次；单次最多 2048 个文件/目录、深度 16、总资源 2 GiB。

点击目录进入，HTML/CSS/JS/JSON/TXT/SVG/XML/Markdown 进入源码页，其它文件可预览图片、视频和音频。单项菜单与多选栏均提供可见的移动、复制入口；独立目标目录弹窗只浏览文件夹，始终提供面包屑和取消，不需要寻找隐藏的粘贴入口。文件菜单还提供重命名和设为主页面。主页面及其父目录不可直接删除，须先指定另一 HTML 页面。

通用文件行至少 72 dp，主/副行始终占位，尾部 48 dp 在更多菜单与选择框间切换。长按多选、取消与操作切换不会改变行高；删除须确认，弹窗与按钮使用主题动效/触感。源或目标目录消失时明确报错并保留原文件，不默默失败。移动/重命名主文件或其目录会更新主页面引用。

“预览页面”进入正常子页，返回文件管理器，不替换当前大字幕。宿主项目目录为 `appdata/Kigtts/media/<id>/`；嵌套主页面只能引用项目内资源。文件修改与主页面切换更新版本，再次呈现加载新内容。网页保留 Cookies，“设置 → 网页”可清除。

通用交互也供插件 `PageBlock.Files` 使用，插件只提供相对目录/条目/动作，由自身处理文件 IO、目标冲突和失败提示。Lua/原生编辑器的项目资源仍保存在各自 `appdata/Kigtts/plugin/plugindata/<pluginId>/`，不混入宿主 HTML 目录。参见 [插件页面规范](plugin-page-style.md)。

## 源码编辑

独立编辑页提供名称、保存、查找替换、等宽源码与行号。源码不自动折行，横/纵独立滚动，当前行号高亮。键盘上方图标栏常驻，可左右滚动或展开多行：

- 撤销、重做。
- 光标左、右、上、下，行首、行尾及 Tab。
- `(`、`)`、`{`、`}`、`<`、`>`、`'`、`"`、`;`。

符号替换选区，光标按 Unicode 码点移动，上下键按逻辑行保持列位置；操作后保留焦点。宿主 HTML 文本文件最多 UTF-8 2 MiB，撤销最多 20 步并限制总内存，保存以 UTF-8 无 BOM 原子替换。有修改时返回需确认放弃。大草稿/光标在私有缓存，Bundle 只保存 token。

API9 的插件 `PageBlock.SourceEditor` 复用相同组件，独立限制为最多 64,000 字符。保存回调 `inputs["value"]`，插件负责写入、版本检查与审核；超出限制不截断写回。普通编辑/输入页面共用正常层级过渡与预测返回，不使用条目全屏模态变换。
