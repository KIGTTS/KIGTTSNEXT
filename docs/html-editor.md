# HTML 文件与编辑器

页面卡片的“创建页面文件 / 管理页面文件”打开独立的项目文件管理页面。字幕、缩略标题及条目草稿继续保留，返回后可保存条目。已有宿主 HTML 沿用原来的媒体 ID 和项目目录；插件 HTML 复制为宿主项目，不改写插件资源。远程 HTTPS 页面可直接选用，编写本地页面时创建独立项目。

## 文件管理

项目支持多级目录。顶部操作提供预览、新建文件 / 文件夹、批量导入文件或媒体、导入整个文件夹；导入保留文件名称和目录结构，同名文件自动编号，失败回滚本批次。每次导入最多 2048 个文件或目录、目录深度 16、总资源 2 GiB。

点击文件夹进入，左侧上一级按钮返回目录；点击 HTML、CSS、JS、JSON、TXT、SVG、XML 或 Markdown 文件进入源码编辑。其它文件可预览图片、视频和音频。长按进入批量选择，可复制 / 移动、在目标目录粘贴或确认删除；文件菜单提供重命名及设为主页面。主页面及其父目录不能直接删除，需要先指定另一 HTML 页面。

“预览页面”进入正常子页面，返回文件管理器，不替换当前大字幕。页面项目目录为 `appdata/Kigtts/media/<id>/`；嵌套主页面可以引用项目内的相对路径资源，不能访问项目以外的文件。文件修改和主页面切换会更新内容版本，已显示网页再次呈现时加载新内容。网页的 Cookies 及设置中的清除入口沿用现有行为。

## 源码编辑

独立编辑页面显示文件名称、保存、查找替换、等宽源码和行号。源码不自动折行，横向 / 纵向独立滚动；当前行号高亮。键盘上方的图标快捷栏常驻，可左右滚动，展开后按宽度排列成多行：

- 撤销、重做。
- 光标左、右、上、下，行首、行尾及 Tab。
- `(`、`)`、`{`、`}`、`<`、`>`、`'`、`"`、`;`。

符号替换当前选区，光标按 Unicode 码点移动，上下键按逻辑行保留列位置。操作和展开快捷栏后保留编辑焦点。每个文本文件最多 UTF-8 2 MiB，撤销最多 20 步并限制总内存；保存以 UTF-8 无 BOM 原子替换当前文件后返回管理器。有修改时返回需要确认放弃。大草稿和光标在私有缓存中保存，系统恢复的 Bundle 只记录 token，避免将源码直接放入 Bundle。

## 回归范围

本地测试包含目录结构及相对资源、主页面保护、重命名 / 移动后更新主页面、导入同名处理与失败回滚、SAF 目录导入、插件副本隔离、Unicode 光标及选区撤销、缓存草稿恢复、原生行号与键盘避让、快捷栏展开及编辑焦点、文件保存和页面层级返回。系统选择器、实际键盘、网页交互及视频 / 音频解码仍需手机验收。
