# 原版 KIGTTS 内容兼容

设置 → 备份与还原 → 旧版 KIGTTS → 导入旧版备份。根据包内格式标识识别，不依赖文件后缀；导入前显示内容数量与分组，确认后追加，不覆盖现有内容。

|原版格式|目标|
|---|---|
|`.kigtpk` / `quick_subtitle` JSON|快捷文本分组、原有顺序、颜色与 Material Symbols 图标|
|`.kigspk` / `soundboard`|快捷文本音频卡片分组，保留音频原件及非破坏式播放裁剪区间|
|`.kigcard` / `kigtts_quick_cards`|拍立得的“旧版 KIGTTS 名片”独立相册|
|`.kigconfig` / `kigtts_config_backup` 1–2|提取上述三类内容与随包资源；不覆盖当前应用设置、引擎、字体及语音模型|

名片同时有横竖图片时分别生成两张；没有图片时生成原背景色的纯色图片，纸边仍保持纯白。二维码作为可调整的图片贴纸，保存原 Unicode 内容并放在照片窗口中央。名片标题与备注保留，原图另作原件引用。

使用确定性内容标识检查重复。重复导入跳过已有条目，不会覆盖后来编辑的内容；原分组改名后仍能按稳定分组 ID 识别。照片先分批规划后一次提交目录，快捷文本按修订提交；跨两类目录中断后可以重新导入以补齐未完成部分。

导入仅在私有缓存中解包。限制归档大小 2 GiB、元数据 16 MiB、JSON 深度 32、文件数量 12000；拒绝路径穿越、重复归档路径、重复内容标识与缺失媒体。旧版完整备份里的绝对媒体路径，只映射到备份的 `resources/quick_cards` 与 `resources/soundboard`，不读取所指的任意本机路径。旧版未随包导出的图片或音频需要重新从原版选择包含资源的导出。

## 后续覆盖原版安装

当前仍使用 `com.kigtts.next`，没有改包名。为未来原位升级预留了自动迁移：启动时检测本应用私有目录的 `datastore/user_prefs.preferences_pb`，复制为临时快照，用原版相同的 Preferences DataStore 格式读取 `quick_subtitle_config`、`soundboard_config`、`quick_card_config`。仅访问原私有 `quick_cards` 与 `soundboard/audio` 资源，不修改原设置或原资源。成功后记录独立完成标志；失败不标记，下次仍可重试。

实际覆盖发布前还需使用原包名 `com.lhtstudio.kigtts.app`、匹配原版签名并提高 versionCode（已检查原版为 10），同步管理桥绑定目标和签名权限配置。不同包名之间不能直接读取对方私有目录，本次不尝试越过 Android 应用隔离。

## 快速排序与主界面侧滑

非编辑模式长按快捷文本或分组，首次显示开启说明；可在设置 → 操作反馈 → 长按快速排序中修改。排序使用编辑模式同一持久库，支持横列、宫格和边缘自动滚动。首次提示及拒绝后长按不会发送条目；普通点击继续发送。

主界面左滑打开拍立得、右滑打开画板，页面跟随手指，取消回到主界面；子控件滚动、文字选择、双指操作及系统返回边缘优先。横竖屏使用相同滑动方向。拍立得入口长按直接打开相机，并遵循已有默认系统相机设置。

娃语格式由独立 [娃语预设兼容插件](https://github.com/KIGTTS/plugin-kigusay-backup) 提供，出现在自己的备份卡片内，保留 GPL-3.0-only 许可。
