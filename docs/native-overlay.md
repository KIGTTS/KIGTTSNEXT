# 悬浮快捷入口

主软件原生功能，入口在“设置 → 外观与交互 → 悬浮窗”。首次默认关闭，由用户通过系统悬浮权限开启。闲置贴边收起与淡化默认开启；拖动调整位置，点按展开，长按打开设置。展开使用主软件 M3E 色板、圆形至 Cookie12Sided 形变和 Expressive 动效。

展开列表上下滚动，首尾有阻尼，最多100个入口。设置列表支持手柄拖拽、跟手浮层、邻项让位和边缘自动滚动，松手后一次保存。默认入口为字幕板、拍照、拍立得和画板；旧版大字幕与快捷文本入口合并在原有首个位置。添加入口按软件页面/操作、插件名称与页面/操作、应用逐级选择，并支持搜索。应用列表和可见图标在后台读取，磁盘与内存缓存复用图标，缓存随应用版本更新。仅查询 MAIN/LAUNCHER，不申请 QUERY_ALL_PACKAGES。

窗口按系统栏、刘海和当前屏幕重新定位；收起时只保留80dp小窗口，展开时也不创建全屏触摸遮罩。与原有悬浮聆听字幕共存。服务使用 specialUse 前台类型，有持续通知和关闭操作；不在开机时自行启动、不启动录音。系统收回悬浮权限后关闭服务。原生系统授权需真机手动完成。

“优先小窗打开”为默认开启的总开关，KIGTTS 已正常全屏位于前台时，软件内入口保留原窗口。小米沿用已适配的系统自由窗选项；其它设备请求系统 freeform 模式，由系统选择原生比例和密度。系统拒绝时降级正常打开。[Android ActivityOptions](https://developer.android.com/reference/android/app/ActivityOptions)

## 插件接口（API22）

包声明 `overlay` 及 permissionPurposes。通过调用方绑定的 AppBroker 使用 `AppCommand.Overlay`：

- `status`：查询开关与系统授权，不能开启悬浮窗。
- `register`：注册 OverlayEntrance 候选，不自动添加。可选 category 指定分类，badge 复用 PluginBadge（主题、警告、黄色，圆点或数字；大于99显示99+）。再次注册相同ID更新其状态。
- `request-add`：注册并排队原生确认弹窗，用户手动同意后才添加。完全访问不绕过本权限和添加确认。
- `bubble`：显示原生文字气泡，可带图标文字按钮，actionId/pageId二选一。文本最多180字，按钮最多24字，2–30秒自动关闭。
- `clear-bubble`：只关闭自己的气泡。

宿主自动把已启用插件的设置页、抽屉页和顶栏动作列为候选；插件也可注册自定义入口。候选仅用于用户手动选择，不直接写入悬浮入口。

入口绑定插件ID和签名发布者。停用/卸载清除候选、待确认和气泡；保存的入口保留置灰，重新启用同一发布者的插件后恢复。应用卸载后入口也保留置灰；点击前再次核验可用性。状态气泡与宿主顶栏共用动效和颜色，刷新气泡不会打断闲置贴边收起。导出 Activity 只接受宿主创建的一次性不透明入口令牌，不接受任意插件ID或操作参数。

## 本轮验证范围

电脑 Robolectric/Compose 覆盖窗口生命周期、权限拒绝、旋转安全范围、入口排序、拒绝/确认、伪造与重复路由、展开/收起、亮暗主题及全局震动开关。用户已带走设备，本轮不宣称通过厂商悬浮授权、真实跨应用拖动、小窗行为或实机动效验收。

## 字幕区域手势避让

主页使用 `Modifier.excludeHomeSideSwipes` 按区域保留横向手势，生命周期结束自动释放；接口不消费子页面指针事件。HTML/网页和声明 SUBTITLE_STROKE 的启用插件自动接入。自定义字幕渲染器通过 `PanelPresentation(blockHomeSideSwipes = true)` 请求相同避让。区域外仍可侧滑进入画板或相册；关闭手势插件后恢复原有侧滑。
