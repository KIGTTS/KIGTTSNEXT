# 名片背景与头像形状

2026-10-26

名片背景不再使用固定 216px 高的位图覆盖实时照片。显示时按实际物理像素向上取 128px 桶（256–1536px 高），后台生成 PNG 无损预烘焙；源照片最长边解码上限 3072px。昵称、简介、头像、联系方式和贴纸在背景之上独立绘制。

## 缓存和实时编辑

- `IdentityBackgroundCache` 由 `StickerRepository` 持有，显示缓存 24MiB、源素材缓存 48MiB，磁盘 PNG 按最近使用保留至 96MiB。共享像素淘汰时不直接回收，避免销毁仍在屏幕上的帧。
- 背景键包含源文件路径、时间及大小、照片位置/缩放、底色、花纹、渐变和边框资源。个人资料和贴纸编辑不使背景失效。
- 应用启动及选中背景变化时预热；进入设置优先取内存，改变尺寸时保留已有清晰背景，新的尺寸在后台就绪后替换。
- 编辑使用预解码照片、预模糊纹理及记录好的矢量花纹/边框。每次手势直接更新画布上的照片位置和缩放，不触发图片解码或等待 PNG 烘焙。
- 模糊沿用线性光 float32 高斯卷积和稳定的降位深抖动。渐变关闭时不会增加底部模糊；渐变开启时保留未遮罩区域的原始清晰照片。
- 渐变新建默认关闭；迁移时缺少开关字段也视为关闭，明确保存的开启状态不变。导出复用相同背景绘制结果。

## 头像形状

头像形状为横向滚动的图形单选列表，使用当前 Material3 的 35 种形状。已有 `circle/flower/cookie/clover/sun` 标识保持兼容，默认仍为圆形。

切换以 300ms 缓动插值等弧长轮廓；连续改选从当前可见轮廓继续。停止后采用原始矢量曲线。图片裁剪、导出和 `publicJson.avatarClipPath` 使用同一单位方形 SVG 路径，网页可直接复用。

## 联系方式

名片中的社媒图标使用白色前景、投影和向边缘渐隐的半透明暗底。前五个直接展示，第六位为横向三点；点击后可选择后续联系方式并打开二维码及 NFC 入口。导出的图片使用相同的五个图标加省略号布局，完整联系方式仍保留在名片数据中。

## 验证

最终合并的 28 项定向回归全部通过，覆盖 Android 8/15 的四像素条纹清晰度、PNG 重开逐像素一致、缓存复用及失效、编辑姿态不重复解码、35 种 SVG 路径和连续改选、真实 Compose 花型选择保存、双指未松手前更新照片、名片资料迁移、头像裁剪与共享编辑器交互。

其中社媒追加 2 项检查：原生界面的五项/省略号/更多菜单/二维码交互，及导出图标数量、白色三点和半透明渐隐暗底。Release/R8 和 Lint 成功，Lint 为 0 错误；建议改用 KTX 等既有级别警告仍存在。
