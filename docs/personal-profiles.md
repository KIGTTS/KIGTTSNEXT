# 个人信息与扩列收藏夹

设置顶部进入“个人信息”。每位用户只有一张个人名片，头像、昵称、简介、联系方式、标签和磁贴属于同一份资料。旧版多背景迁移保留当前选中的名片，旧数据归档且不删除设计素材。

## 编辑个人主页

- 标签：添加、移除，最多 12 个，每个最多 20 字。
- 磁贴：链接、社媒、标题、文字、图片，图片支持 GIF。
- “编辑磁贴”后点击磁贴编辑内容，长按拖动调整顺序，拖右下角弧形手柄调整大小；保存布局后生效，取消保留原布局。
- 标题固定整行，使用一行文字的高度加少量间距，不占普通磁贴的一整行高度。其它磁贴可占 1–4 列、1–3 行，使用四列网格自动避让。标题后的内容不会回填到标题上方。
- 社媒磁贴引用已有联系方式，使用同一套 Remix 图标，点击显示二维码；删除联系方式后保留不可用磁贴，编辑时可重新选择。
- 图片保留原文件，GIF 不会被压成静态图保存。后台解码、限制解码尺寸，离屏和退到后台暂停动画。Android 8 的动画解码器无法采样，超过 400 万像素的 GIF 使用静态缩略预览，原文件仍可完整分享。

名片封面继续支持背景、头像形状、边框和贴纸编辑。左上联系方式使用相连按钮组，右上提供“开启面对面”。

## 面对面与收藏

名片和照片分开处理：收到名片后保存到“扩列收藏夹”，不会作为照片塞进拍立得相册。查看照片发送者资料时，也可主动“加入扩列收藏夹”。

收藏夹纵向排列名片，点击展开资料、标签、磁贴和联系方式，再次点击收起。支持按昵称、简介和标签搜索，以及确认移除。列表按需加载可见卡片，资料搜索索引在后台构建。保存的是独立资料快照和图片缓存，发送方关闭分享后仍可查看；同一身份再次发送会更新已有收藏。

扫码网页与原生资料页共享标签和磁贴布局、Remix 图标、主题角色、明暗模式和用户圆角。网页保留联系方式二维码、复制和网址入口；照片分享保留原有预览、选择和下载流程。网页分享会话关闭后，原访问入口失效。

## 实现与验证边界

资料、布局、收藏缓存、界面和网页组件分别维护，避免把编辑和网络协议堆到单个页面。

个人资料和图片独立传输：图片使用 `PROFILE` 附件，支持 JPEG/PNG/WebP/GIF，单附件最多 20 MB；资料最多 256 KiB UTF-8，JSON 消息与响应有 384 KiB 上限。数据解析限制字段数和尺寸，网页转义文本，仅渲染内置矢量，不执行收到的 SVG 或自定义 URL scheme。收藏缓存按内容哈希保存原始图片，资料使用原子写入。

本轮 62 项回归通过，覆盖单名片迁移、磁贴持久化和尺寸布局、Robolectric 手柄拖动、收藏纵向展开与 40 张收藏按需组合、GIF 完整传输与缓存、TCP 大资料交换、网页二维码与主题、安全模式和插件源图标尺寸。图片解码在 API 26/35 验证尺寸限制和损坏文件，在 API 28/35 验证 GIF 绘制及启停；Android 8 的 Movie 动画仍待对应设备验证。另在手机和桌面宽度的真实浏览器中检查了网页布局、二维码、照片翻页、选择和动态主题，控制台无错误。双机 BLE/Wi-Fi 建连及厂商系统限制仍以实际设备为准。
