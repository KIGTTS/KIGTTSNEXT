# 拍摄位置与天气

“设置 → 拍照 → 拍摄信息”提供统一的记录开关和“天气设置”入口。开关沿用已有地点/天气授权对应的开启状态；显式关闭后，新拍照片不主动获取位置或天气。日期、时间与原始照片保持不变。编辑已有照片时仍可主动添加拍摄信息。

天气设置包含：

- 自动位置：新拍照片可使用手机定位，导入照片只使用照片自身坐标。
- 手动位置：填写地点名称和 WGS84 经纬度，只用于新拍照片；不把当前位置套到没有 GPS 的旧照片。
- 地名数据源：系统优先（失败后使用离线地名）、仅离线地名、高德地图。
- 天气数据源：Open-Meteo、UAPI、高德天气、心知天气。需要密钥的来源分别保存在应用私有偏好中，不写入照片或分享内容。

首次使用位置前先解释用途，再请求系统权限。对高德地名查询、不同天气服务分别记忆授权，切换服务不会沿用其他服务的同意记录；一次查询固定数据源配置。

## 数据源

| 来源 | 配置 | 查询范围 |
| --- | --- | --- |
| Open-Meteo | 无需密钥 | 保留原有按拍摄日期、小时查询与历史查询；免费服务仅限非商业使用 |
| UAPI | 无需密钥 | 城市天气实况；从照片经纬度离线匹配 25 公里内的城市，仅发送城市名，不使用请求 IP 定位；城市无法匹配时显示未知 |
| 高德地图/天气 | Web 服务 API Key | 中国地区地名和天气实况；GPS 先通过官方坐标转换接口转换为高德坐标，再查询行政区与天气 |
| 心知天气 | API Key | 按经纬度查询城市天气实况 |

UAPI、高德与心知的实况仅用于三小时内的近期拍摄，校验返回的观测时间。UAPI 支持绝对时间和“几分钟前发布”类相对时间。无对应历史数据、缺少密钥、超时、错误响应或字段缺失时显示“未知”，不以今天的天气填补旧照片，也不悄悄切换到另一家服务。网络和 ROM 定位仍有有界等待，失败不会无限阻塞保存。
