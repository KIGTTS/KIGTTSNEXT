# 插件安装界面

本地导入、商店安装计划和首次下载商店，统一使用宿主原生安装器。顶部保留插件图标、名称、作者（包内声明时）、版本及包大小，不再添加“插件安装器”标题。

介绍、权限、许可三个页签共用固定高度的内部滚动区，底部“取消 / 安装插件”始终可见。依赖计划按已检查的顺序安装，部分成功时列出已安装项，重试跳过本次已完成的包；降级仍需显式版本切换请求。成功后停留在完成页，由“安装完成”关闭或继续原引导。

权限页只展示能力和用途，没有勾选、开关或安装时授权。安装过程不写入权限授权账本；新插件的受控能力在真正调用时，沿用“授权 / 仅本次允许 / 禁用”流程。更新保留原有权限决定，不默默放宽权限。

## 可选的包内介绍

插件可携带 `assets/plugin-info.json`：

```json
{
  "description": "支持 Markdown 的插件介绍。",
  "author": "作者名称",
  "symbol": "graphic_eq"
}
```

它必须列在已签名的 `plugin.json.files` 中；安装器只读取清单中的资源，不运行候选代码获取介绍。元数据文件最多16KiB，介绍最多8000字符、作者120字符、Material Symbol 名称80字符。无介绍时显示简短的宿主说明，无图标时使用能力图标。

许可正文从清单中的根目录 LICENSE/NOTICE 或 `assets/licenses/`、`licenses/` 的文本文件读取，最多16份，每份128KiB，总量256KiB。未附正文时只展示声明的许可证名称及缺失说明，不生成替代条款。正文与发布者指纹可选择复制。

主程序仍检查包签名、全部有效载荷哈希、设备兼容性、发布者一致性和版本替换规则。包内作者、图标和介绍只是展示信息，不替代验签发布者身份；原生代码的权限边界见[插件权限](plugin-permissions.md)。

## 朗读服务引导

没有安装语音合成服务时，点击朗读可选择“前往安装”“稍后再说”“不安装并隐藏朗读按钮”。“稍后再说”只关闭本次引导，保留朗读入口；隐藏选择在重启后保留。安装并启用语音合成服务后入口自动恢复，停用或服务不可用时自动隐藏，已有的媒体全屏按钮和插件入口不受影响。

前往安装会打开商店中的语音合成服务搜索结果；没有商店时先明确询问下载商店，再经过同一原生安装器确认。不会仅因点击朗读就开始下载。
