# 2026-11-18 插件界面与提示检查

宿主提供的权限标题、授权方式、能力名称和安装审查提示已接入四套目录。具体权限用途来自插件签名包，仍可能只有中文；这部分应由插件补齐，宿主不改写发布者的权限说明。
