# 插件页面与设置风格

当前插件使用 API9、版本 0.8.0。插件声明数据与动作，宿主提供主题、字号、相邻圆角、触感和过渡；不向插件暴露独立 Compose 样式或自定义控件尺寸。

## 设置与入口

主页设置键直接进入设置。`SettingsEntry` 把插件页面放入相同的双层卡片：保留类别 appearance/audio/content/extensions 使用宿主标题，其它 cardId 可创建自定义卡片。旧 DrawerEntry 兼容迁入设置，同 pageId 的正式入口优先；当前界面没有抽屉。

页面标题只放在 `PluginPage.title`；与它完全相同的顶层正文 heading 不重复显示。分组标题/说明与内层条目沿用相同字号，说明只描述实际用途，避免重复版本、引擎数量、协议或空备注。`PluginIcon.NONE` 完全省略图标，不留下占位。

`PageBlock.Group` 提供外层卡片，内部 Actions、Toggle、Choice、Input 使用设置条目。相邻内卡保持小接缝圆角、首尾大外圆角，颜色和圆角随设置缓动。Choice 使用相连按钮，按下即有形变/触感，松手或取消正确复位。

小型 ManagementList（1–32 项，无排序/筛选/头像/置顶/附加菜单）可复用设置行：group 是分组，primaryAction 是入口，toggle 是开关，selected 是选中标记。带排序/资源操作的集合使用虚拟化管理列表；无操作时不显示空菜单。

## 导航与刷新

页面预加载并缓存，返回或再次打开已有页不重放全部条目的初次动画。插件用 `uiChanges` 通知失效；宿主按稳定身份更新局部内容。新旧条目、提示、选中状态和操作有过渡，旧项退出后立即禁止输入。短暂加载/页面退场保持原配色，避免闪成不可选态；真实 enabled 状态变化仍有主题过渡。

LargeFlexibleTopAppBar 随滚动变化，背景与转场覆盖状态栏。顶层 Actions 映射本页顶部操作，前两项直接显示，其余进入更多；Group 内动作在组内。忙碌环形进度在展开栏位于返回键右侧，收成单行后位于标题后。子页没有全局抽屉入口，进入/返回与预测性返回沿正常层级导航，方向固定为页面入场侧。

## 专用原生组件

- SourceEditor：独立源码页、行号、查找替换、撤销/重做和键盘上方可滚动/展开快捷栏。保存回传文本，插件处理写入与审核。
- Files：面包屑、多选、可见移动/复制、独立目的目录选择及删除确认。行至少 72 dp，空副标题仍占一行、尾部统一 48 dp，多选与更多菜单不改变行高；文件 IO 和失败提示由插件负责。
- Chat：稳定 ID 消息气泡、流式内容、可选服务公开思考内容、输入/停止。完整历史保存在插件，宿主只显示有界快照。

这些组件使用宿主动效、圆角与按压反馈；自定义网页 DOM 内的动画由页面作者控制。

## 服务页面

语音合成服务按“朗读”“声音资源”“加载方式”组织，直接显示声音、语速、语音包和保持加载，不重复当前引擎、声音数量或页面标题。系统 TTS 内置为保底，不作为独立包入口。

语音识别服务统一管理聆听字幕、语音输入和引擎资源。配置采用分组、开关与相连选择器；提供者列表可排序，子页保留启用、选用和识别包入口。识别方式明确显示“边说边识别”“分段识别”“完整录音”，不声称标签修改能增加模型语言能力。
