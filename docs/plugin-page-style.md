# 插件页面与设置风格

插件继续通过 API8 声明内容，颜色、尺寸、触感与过渡交给宿主。此次调整没有增加 SDK 类型，现有 API8 包也能使用新的宿主样式。

## 配置页面

- 页面标题只放在 `PluginPage.title`；宿主会忽略正文中与它完全相同的顶层 heading，不删除其它说明。
- `PageBlock.Group` 采用设置页的外层卡片，内层 `Actions` 采用图标、文字、入口箭头的条目，相邻条目保持内侧小圆角、首尾外侧大圆角。
- 小型 `ManagementList` 使用相同设置组件：1–32 个条目、无排序/筛选/头像/置顶/附加菜单时，`group` 为卡片分组名，`primaryAction` 为入口，`toggle` 为开关，`selected` 为当前选择标记。说明只描述实际选项或操作效果。
- 可排序、带资源操作的集合和较大列表继续使用虚拟化管理组件；没有条目操作时不显示空的更多菜单。
- 顶层 `Actions` 保持页面顶栏操作；频繁使用的配置放在正文，避免将全部配置藏在顶栏菜单。

标题和副标题沿用设置字号，配色跟随主题。普通说明采用表面色系。内容/选中标记/条目更新保留过渡；短暂加载和页面退场阻止操作并保持原颜色，避免闪成禁用灰色。

## 服务页面

语音合成服务 0.7.3 将配置分为“朗读”“声音资源”“加载方式”，直接显示选用的声音和语速，提供语音包管理及保持加载。声音选择页沿用原来的跨插件声音 ID 与选择动作，分页显示；语音包排序、启停与资源目录保持原逻辑。去除重复标题、当前引擎提示、声音数量和空备注占位。

识别服务 0.7.1 保留可排序的提供者列表；子页统一为“启用”“用于识别”及提供者设置入口。去除重复引擎状态、服务架构说明和采样率正文，采用“边说边识别”“分段识别”“录音识别”等操作文案。
