# 拍立得浏览与相册

拍立得主页默认逐张浏览，以三层平面相纸堆叠呈现。滑动时保留平面倾斜角度，不使用三维透视；前卡自然退出，后卡承接，绘制顺序不会在半页时突然互换。三层纸面保持不透明，后页文字不会透过前页白边。偏移在布局放置与图层阶段读取，不因每个动画帧重新组合整张相纸或重新解码照片；分页只保留附近卡片。

顶部的宫格按钮切换逐张与宫格；宫格另有列数按钮。双指收拢可进入宫格并增加到 2／3／4 列；4 列是照片宫格最密的一档，再次缩小进入相册总览。反向放大从相册总览恢复照片宫格，再逐级减少列数，回到逐张浏览。宫格只显示当前相册，逐张浏览按相册与照片顺序连续翻页，末尾进入下一本有照片的相册。手动选册或选图优先于先前未结束的拖动与惯性，定位保留过渡。

竖屏的相册栏位于底部，相册和照片预览横向滚动；横屏位于右侧，两组分别竖向滚动。选中项会自动进入可见范围，栏可展开和收起；新增 FAB 位于浏览区域，随相册栏占用空间避让。收展只切换端点布局尺寸，过渡在图层进行，避免整张照片和文字逐帧测量。横屏标题使用沉浸式单行窄顶栏，竖屏继续 large flexible，根据实际窗口尺寸切换而非锁定屏幕方向。浏览位置、宫格密度与展开状态在页面保存状态中保留，所选相册也保存到本机偏好。

单击照片打开透明全屏浮窗预览，双指缩放的是整张带边框、文字、Logo 和贴纸的拍立得；预览不改变照片构图，裁剪和平移照片仅在编辑页进行。返回或关闭后保留浏览位置；长按照片或浮窗的编辑按钮进入正常编辑子页。分享、添加到快捷文本、复制、移动到相册及删除可从预览操作。删除照片和相册均需确认。插件 `OpenUi(CARDS,cardId)` 使用同一浮窗，旧内部预览导航也转到这一入口。

默认相册 `user.polaroids` 不能删除；旧照片自动归入其中。新建空白、选图和拍照放入当前相册。删除其它相册时，其照片追加回默认相册，照片及图片资源保留。每张拍立得只属于一册，相册和照片各自保存顺序，更新在共享 catalog 内原子提交。插件和 Agent 的读取、移动、排序接口见 [图库与拍立得合同](stickers-api.md)，开发模板在独立私有仓库。

在浏览区域下滑可跟手进入原生相机，相机上滑返回相册；点击拍照入口也使用同一垂直过渡，预测性返回保持向上退出。双指、滑条、相册栏和按钮操作不触发页面切换，保存或打印期间的保护状态会阻止手势绕过操作锁。

新照片拍摄并保存后，相机场景显示随主题配色的 KIGTTS 打印顶栏，相纸从打印槽逐步送出。打印完成返回相册，新照片的透明全屏预览浮窗覆盖在相册之上；关闭预览即可继续浏览。打印被子页面暂时覆盖时保留请求，返回后继续完成；从编辑页重拍仍先回到编辑草稿。

默认纸面和内置细框使用纯白，预览与 PNG 导出共享颜色解析。旧经典纸框的默认奶黄会转白，自定义色和品牌素材保留。经典默认纸框右下显示 KIGTTS 横版 Logo，标题和说明避让；预览与 PNG 导出位置一致，品牌和自定义边框不被强制添加 Logo。相机只显示照片窗口，拍摄之后才添加相纸，操作布局、构图辅助和资源释放见 [内建相机](../app/src/main/java/com/kigtts/next/ui/cards/camera/README.md)。构建、本地交互回归和真机验收分别记录在 [Release 验证](release-testing.md)。
