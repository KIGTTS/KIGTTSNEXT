# 拍立得浏览与相册

拍立得主页默认逐张浏览，以三层平面相纸堆叠呈现。滑动时保留平面倾斜角度，不使用三维透视；前卡自然退出，后卡承接，绘制顺序不会在半页时突然互换。三层纸面保持不透明，后页文字不会透过前页白边。偏移在布局放置与图层阶段读取，不因每个动画帧重新组合整张相纸或重新解码照片；分页只保留附近卡片。

顶部的宫格按钮切换逐张与宫格；宫格另有列数按钮。双指收拢可进入宫格并增加到 2／3／4 列；4 列是照片宫格最密的一档，再次缩小进入相册总览。反向放大从相册总览恢复照片宫格，再逐级减少列数，回到逐张浏览。宫格只显示当前相册，逐张浏览按相册与照片顺序连续翻页，末尾进入下一本有照片的相册。手动选册或选图优先于先前未结束的拖动与惯性，定位保留过渡。

竖屏的相册栏位于底部，相册和照片预览横向滚动；横屏位于右侧，两组分别竖向滚动。选中项会自动进入可见范围，栏默认折叠，可以展开和收起；主页不再显示 FAB。展开相册栏时顶栏收成单行，收起后恢复正常 large flexible 行为。收展只切换端点布局尺寸，过渡在图层进行，避免整张照片和文字逐帧测量。横屏标题使用沉浸式单行窄顶栏，根据实际窗口尺寸切换而非锁定屏幕方向。浏览位置、宫格密度与展开状态在页面保存状态中保留，所选相册也保存到本机偏好。

相册栏、普通按钮和顶栏操作共用主界面的主题配色与按压反馈。当前相册和新增入口使用主题主色，其余小按钮沿用主界面色调；亮色默认小控件保持清晰对比，深色、壁纸取色和手动对比度随全局设置变化。控件圆角也跟随全局档位，选中相册保持胶囊形状；相纸及品牌边框继续使用独立纸面样式。

单击照片打开透明全屏浮窗预览，双指缩放的是整张带边框、文字、Logo 和贴纸的拍立得；预览不改变照片构图，裁剪和平移照片仅在编辑页进行。返回或关闭后保留浏览位置，浮窗的编辑按钮进入正常编辑子页。分享、添加到快捷文本、复制、移动到相册及删除可从预览操作。插件 `OpenUi(CARDS,cardId)` 使用同一浮窗，旧内部预览导航也转到这一入口。

编辑页底部工具可以上下滚动，只有顶部手柄区域负责拖动展开或折叠。键盘出现、切换裁剪／贴纸工具或旋转屏幕后仍保留草稿和可滚动的内容区；拖动面板时相纸随实际位置调整，不逐帧重新测量照片。

宫格长按照片进入原位置多选整理；逐张浏览长按后，同一张大相纸缩小，其余小纸向左右展开为水平排列。单击选择或取消选择，长按照片或拖动手柄排序，移动中只改变本地位置，释放后提交一次顺序；拾起、跨排序位置与释放都有触觉反馈，浮层保留至归位。可以全选、批量移动和删除，选择目标相册后仍需确认移动，删除也需确认。相册栏长按或其更多菜单的整理入口可多选相册、拖动排序和重命名；批量删除保留默认相册，其他册的照片迁回默认册。返回和预测性返回先退出整理，管理期间不触发下拉拍照。

默认相册 `user.polaroids` 不能删除；旧照片自动归入其中。相机选图和拍照放入当前相册的最前面，跨册移入也按请求顺序放到前面；已有照片的手工顺序保留，编辑内容或重复移到同册不会把照片移前。原生界面不提供创建空白照片，插件仍可通过正式 `PutCard` 事务强制创建空白拍立得。新加入照片记录真实加入时间，旧照片未记录日期时保持未知，不编造拍摄时间或重排原顺序。删除其它相册时，其照片追加回默认相册，照片及图片资源保留。每张拍立得只属于一册，相册和照片各自保存顺序，更新在共享 catalog 内原子提交。插件和 Agent 的读取、移动、排序接口见 [图库与拍立得合同](stickers-api.md)，开发模板在独立私有仓库。

接收照片预留原生只读属性，允许查看、分享、导出至快捷文本以及移动、排序和删除；照片内容、构图、文字、贴纸和边框不可编辑。原生复制保留只读属性。限制在统一仓储中执行，插件提交同样受限；现有自有照片保持可编辑。面对面搜索、传输和接收流程尚未实现，发现开关当前仅保留设置与入口。

在浏览区域或顶栏标题下滑可跟手进入原生相机，相机上滑返回相册；点击拍照入口也使用同一垂直过渡，预测性返回保持向上退出。标题区域随大小顶栏和页面位置更新，返回及页面操作按钮仍优先接收自己的操作。双指、滑条、相册栏和按钮操作不触发页面切换，保存或打印期间的保护状态会阻止手势绕过操作锁。

新照片拍摄并保存后，相机场景显示随主题配色的 KIGTTS 打印顶栏，相纸从打印槽逐步送出。同一张带框相纸从打印位置连续展开为透明全屏预览，预览画面就绪后底层返回相册；预览保留，关闭即可继续浏览。打印被子页面暂时覆盖时保留请求，返回后继续完成；预览尚未就绪时不会提前返回相册或消费打印请求。从编辑页重拍仍先回到编辑草稿。

默认纸面和内置细框使用纯白，预览与 PNG 导出共享颜色解析。旧经典纸框的默认奶黄会转白，自定义色和品牌素材保留。经典默认纸框右下显示 KIGTTS 横版 Logo，标题和说明避让；预览与 PNG 导出位置一致，品牌和自定义边框不被强制添加 Logo。相机只显示照片窗口，拍摄之后才添加相纸，操作布局、构图辅助和资源释放见 [内建相机](../app/src/main/java/com/kigtts/next/ui/cards/camera/README.md)。构建、本地交互回归和真机验收分别记录在 [Release 验证](release-testing.md)。
