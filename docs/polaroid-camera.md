# 拍立得相机与原图

拍立得为原生页面。顶栏相机点击打开内建相机，长按调用系统相机；设置的相机页面可将系统相机设为默认。取景页选择照片按钮长按也调用系统相机。系统相机没有可通用于各厂商的强制Instax画幅参数，因此返回后以最近画幅初始化Mini/Square/Wide构图页，双指定位缩放，确认后衔接打印及相册预览。构图只保存位置/缩放，不破坏原始JPEG；构图请求由ViewModel持有跨旋转保留。

内建相机向CameraX请求最高可用分辨率、MAXIMIZE_QUALITY和JPEG质量98，能力/资源约束时有限回退；不承诺第三方能复现厂商相机的全部私有算法。单张和连拍仅保存原始高清文件及可逆滤镜参数，普通选图保留原始编码字节。编辑页的滤镜页签可实时调整滤镜、强度及特效，恢复原画不重写源文件；预览取消过时处理并保留上一帧，高清导出使用一个可变图及小条带。原有已处理照片保持当前外观，主动调整滤镜时从其保留原图重新处理。

原画、黑白、暖色、冷色、复古保留，新增原创胶片风格与黑金、写意、季风、京都、旧巷，以及用户3D .cube LUT。五种新风格采用同一份33阶LUT处理缩略图、取景、高清成片及实况，强度0回到原画。预设不是富士官方F-Log LUT，也不冒用其分发许可。用户LUT支持2–65阶、DOMAIN_MIN/MAX、三线性插值，拒绝1D混合、异常或不完整数据，单文件16MiB、库最多32项。取景使用GL2二维图集，高清照片用CPU同一采样，实况保存原视频并关联颜色描述供带框/贴纸预览和导出，避免重复破坏原片。

滤镜入口在取景框右下并避开变焦条，展开后隐藏入口，变焦条继续可用。整块主题色边栏附着取景框边缘，变焦区也在背景范围内。滤镜/特效两单图标Tab与收起键都属于强度栏：竖屏Tab在左、收起在右，横屏收起在上、Tab在下。方形缩略图左下说明，竖屏强度在列表上方；横屏右侧竖排、原画在最底，强度滑条在左，列表避让变焦条。参考照片由用户提供，作者Joel Filipe，来源和Unsplash许可记录在app/src/main/assets/camera/ATTRIBUTION.txt。HDR等OEM模式只在相机报告支持时提供，实况保留原有标准模式约束。

特效包含暗角、固定噪点、边缘色散和辉光，可叠加并独立调整强度，在颜色LUT前处理；原画也可单独添加特效。取景与实况使用共享GL函数，高清保存使用保留邻域原始行的CPU条带处理，原始高清照片与原始视频保留。旧实况文件缺失特效字段时默认关闭。本次新增特效按用户要求只编译和安装，未运行自动测试或真机视觉验收。

系统相机照片构图页以无底色的原生勾号确认，提示仅保留“双指调整位置与缩放”；底部或右侧用真实纸张/照片窗比例表示Mini、Square、Wide。编辑工具为覆盖相纸的分段面板，升降不改变纸张视口；贴纸库图片与添加文字支持长按拖入，离开面板自动收起，松手放置到纸张相对坐标，纸外松手取消。

变焦按相机实际报告的范围工作；支持广角时0至1×占滑条前四分之一，1×附近吸附，其后对数映射至最大倍率。不把倍率按钮当作已发现物理镜头。

## 完整系统相机和设计预设

系统相机默认使用`INTENT_ACTION_STILL_IMAGE_CAMERA`打开完整相机，镜头选项由系统相机提供；返回后直接接收本次新增的DCIM照片，再进入构图/打印，不再打开选图器。完整相机不提供可靠的图片回传合同时，先申请系统照片读取授权，再按进入相机前的媒体ID、拍摄/新增时间及相机目录筛选新照片，排除旧图、下载和截图；没有新照片则回到原页面。拒绝照片读取授权时使用直接回传照片的拍照接口，原始图片仍完整保留。部分厂商的`ACTION_IMAGE_CAPTURE`直接回传模式会限制可用镜头，设置可切回该模式，但标准Android接口不保证能强制OEM使用指定广角/长焦镜头。

纸框Tab可保存当前边框、贴纸、文字样式为默认预设，支持应用、切换默认、停用默认和删除。新原生拍摄/导入卡自动应用；不复用原照片或裁剪位置；贴纸生成新ID，每种拍摄字段在每张相纸内有唯一ID，插件强制创建和接收的只读卡不套预设。被预设引用的贴纸图片或自定义边框须先解除预设引用再删除。数据单独存于`cards/design-presets.json`，没有改变API13构造器；渲染后的文字仍是可分享的普通图层。

文字和贴纸Tab通过开关显示日期、时间、日期时间、地点和天气，不重复添加或手动输入同类字段。照片原始EXIF优先；内建相机可用真实拍摄时刻兜底，旧图缺信息时保持开关关闭并提示。字段在备注下方左对齐排列成单行，各自带离线Material Symbols图标；预览、静态和实况导出共用同一排版。过长内容只在这一行适配字号及省略，完整文字保留于数据及无障碍描述。字段冻结保存，之后预览不持续定位或刷新天气；预设保存开关类型，在新照片上重新解析。

地点仅在用户使用字段时原生确认，再按需申请大致定位；旧照片不会使用当前位置冒充历史地点。天气单独确认后将约略坐标和拍摄日期发给[Open-Meteo](https://open-meteo.com/en/docs)，保存拍摄小时的模型估计而非宣称现场观测。数据归属Open-Meteo及其数据提供者，遵循[CC BY 4.0与服务条款](https://open-meteo.com/en/terms)；免费服务仅限非商业用途，商业部署应接入合适的订阅/提供者。相机设置可清除这两项授权；原始照片不上传。

编辑器键盘只抬升工具面板，照片和标题保持原视口。画板擦除触点显示白黑双描边范围环，半径与实际擦除大小/画布倍率一致，抬手和取消即清理。噪点CPU和GPU共用非线性二维混合，移除旧101单元重复格纹；原始照片不改写。
