# 拍立得相机与原图

拍立得为原生页面。顶栏相机点击打开内建相机，长按调用系统相机；设置的相机页面可将系统相机设为默认。取景页选择照片按钮长按也调用系统相机。系统相机没有可通用于各厂商的强制Instax画幅参数，因此返回后以最近画幅初始化Mini/Square/Wide构图页，双指定位缩放，确认后衔接打印及相册预览。构图只保存位置/缩放，不破坏原始JPEG；构图请求由ViewModel持有跨旋转保留。

内建相机向CameraX请求最高可用分辨率、MAXIMIZE_QUALITY和JPEG质量98，能力/资源约束时有限回退；不承诺第三方能复现厂商相机的全部私有算法。原始高清文件保存，滤镜图另存；普通选图保留原始编码字节。单张处理支持上限8000万像素，滤镜使用一个可变图及小条带，不能把这上限理解为所有设备内存都足够。

原画、黑白、暖色、冷色、复古保留，新增原创胶片风格与用户3D .cube LUT。预设不是富士官方F-Log LUT，也不冒用其分发许可。用户LUT支持2–65阶、DOMAIN_MIN/MAX、三线性插值，拒绝1D混合、异常或不完整数据，单文件16MiB、库最多32项。取景使用GL2二维图集，高清照片用CPU同一采样，实况保存原视频并关联颜色描述供带框/贴纸预览和导出，避免重复破坏原片。

滤镜入口始终在取景框右下，实况开关占原滤镜槽。方形缩略图左下说明，竖屏强度在列表上方；横屏右侧竖排、原画在最底，强度滑条在左。参考照片由用户提供，作者Joel Filipe，来源和Unsplash许可记录在app/src/main/assets/camera/ATTRIBUTION.txt。HDR等OEM模式只在相机报告支持时提供，实况保留原有标准模式约束。

变焦按相机实际报告的范围工作；支持广角时0至1×占滑条前四分之一，1×附近吸附，其后对数映射至最大倍率。不把倍率按钮当作已发现物理镜头。
