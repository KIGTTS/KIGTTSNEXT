# 快捷卡片与弹窗

快捷条目由正文和可选的缩略标题组成。没有标题时，卡片只显示两行正文；有标题时，大字显示标题，小字显示正文。发送、编辑和语音朗读始终使用完整正文。旧版本的“说明”迁移为缩略标题，原有 ID、分组、排序和媒体关联保留。

## 四类卡片

正文与可选缩略标题位于四个类型 Tab 上方，属于所有类型的共有字段。Tab 为无、音频、媒体、页面，使用原生图标在上、文字在下的布局及选中指示条；背景继承外层卡片，未选中项使用普通文字色；无表示不附加媒体或页面，仍显示共有字幕。切换时保留正文、标题、颜色、格式和各类型已选择的资源；重新点击当前 Tab 不清除关联。选取文件或页面不会把资源文件名写入正文。

| 类型 | 编辑与发送 |
| --- | --- |
| 无 | 发送共有正文，不附加资源。富文本始终可用，无开关和选区提示。选中文字后，在图标式上下文菜单中设置粗体、斜体、下划线、颜色与字号。共有格式用于所有类型的卡片文字和音频字幕，TTS 接收纯正文。 |
| 音频 | 直接调用系统文件选择器选取音频；发送填写的正文并播放。居中的底部胶囊展开为播放、定位、声音及收起控制，播放结束收回“播放音频”按钮，与实况照片复用同一控件。音频胶囊使用Audio File图标，实况胶囊使用Motion Photos On图标，展开后交叉淡变为播放/暂停。关闭只停止音频、保留字幕。重播和旋转复用同一播放器。 |
| 媒体 | 直接调用系统图片/视频选择器，支持图片、视频和 Android 动态照片。保留原有适应/填充、整卡片模糊背景和缩略图取景。 |
| 页面 | 创建页面项目或选择已有 HTML/HTTPS 页面。内置文件管理器支持目录、批量导入文件/媒体或整个文件夹、选择/复制/移动/重命名/确认删除，以及指定 HTML 主页面；源码在独立子页面编辑，详见 [HTML 文件与编辑器](html-editor.md)。 |

卡片颜色支持默认、自定义和无颜色；自定义调用共用 HSV 取色器，文字自动选用黑色或白色。无颜色移除卡片的底色及媒体封面的主题色遮罩，仍保留媒体图像本身。每条卡片独立保存设置，拖动预览和编辑卡片使用同一文本/颜色组件。

正文限制为 UTF-8 128 KiB。富文本格式保存为 UTF-16 范围，支持输入、删除和替换时重定位；范围与字号经规范化，最多保存 256 段。字号菜单提供小、正常、大三个档位，相对于正文基准字号为75%、100%、125%；正常清除选区的字号覆盖。旧记录的更大字号继续读取，避免已有内容因菜单精简而改变。大字幕首选字号上限为窗口宽度的 50%，仍按内容和可用空间自动适应。取消系统选择器保持原资源；异步导入若对应草稿已取消，只清理本次新导入项。

音频按设备 Media3 解码能力播放，文件保存为宿主持久副本。页面被遮挡或进入后台时暂停，移除内容和 ViewModel 释放时停止；音频播放与语音引擎插件相互独立。

编辑表单按“字幕与标题”“附加内容”“卡片外观”分组，共有字段及分组选择位于类型 Tab 上方，外观选项默认折叠。选择或更换资源为整行入口，移除资源和缩略图取景收进资源菜单。视频/音频显示内容类型或用户填写的标题/正文，不展示文件路径或原文件名；原资源引用保持。类型切换淡入并轻微横移，容器高度缓动；外观选项及资源预览展开收拢，文字本身不缩放，退场内容立即不可操作。

编辑表单直接预览图片、动态照片、视频和音频。预览播放器独立于主界面，初始不播放，手动点击播放；取消、离开、退场或进入后台暂停并释放相应资源。视频与实况的播放控件位于画面下方，预览始终保留完整控制条。音频、视频和动态照片条目提供“自动播放”开关，默认开启，旧条目沿用这个默认值。

视频与实况另提供“音频播放”相连按钮组：不播放、自动播放、跟随朗读设置。视频默认自动播放声音，实况默认静音；跟随档使用顶栏喇叭的设置。画面自动播放与声音策略独立。条目、未保存草稿、显示历史和选中媒体的重启恢复均保存这两项设置；未设置声音策略的旧条目按资源类型使用默认值。播放中的声音按钮仍可手动静音或开启声音。

## 主界面播放与关闭

顶栏/横屏左栏的喇叭是主程序持久化的“自动播放与朗读”开关，不需要插件注册。关闭时暂停独立音频并停止朗读；视频与实况仅在“跟随朗读设置”档跟随声音，画面仍可播放。手动播放和朗读仍可使用。发送纯文本或结束输入时开启自动朗读；实际语音合成继续由可选 TTS 插件执行，未安装引擎时开关也能正常使用。新文本自动朗读替换未完成的旧朗读，避免重复叠加。

打开音频、媒体或网页后，左下角“清空”变为“关闭”。关闭音频只停止播放和移除音频控件，保留当前字幕及选区；独立导入音频也不会用文件名替换字幕。媒体/网页关闭恢复之前的大字幕内容；连续打开多个媒体/网页会逐层恢复，保留原字幕的富文本和光标选区。展示历史最多 16 层，属于当前主程序会话，与二级页面导航独立。删除当前媒体也恢复之前内容，删除音频保留字幕；恢复音频时保持暂停。动态照片打开后默认自动播放一次，完成后回到静态照片；条目自动播放开关决定是否启动画面，不再依赖喇叭。首次页面尚未激活时延后启动，手动暂停后返回不重播，正常播完也不会因页面激活而再次自动播放。

点击视频或播放中的实况画面暂停/继续。播放时 3.5 秒不操作控件，控制栏平滑收窄并下移为半透明进度条；收窄后隐藏手柄，连接已播和未播两段，保持原线条粗细。暂停、触摸进度条或其它播放操作恢复完整控件。拖动期间暂停，启用 Media3 ScrubbingMode，并对每次移动立即请求精确定位，松手恢复拖前的播放状态；离页、关闭或销毁取消拖动恢复。末端拖动保留 1ms，防止一次性实况在拖动期间提前结束。精确定位使用 [Media3 SeekParameters.EXACT](https://github.com/androidx/media/blob/release/libraries/exoplayer/src/main/java/androidx/media3/exoplayer/SeekParameters.java)，实际帧到达时延取决于解码器与文件，不以本地 Player 夹具代替真机跟手性能验收。

媒体库和独立管理器删除资源时先在主线程完成播放器停止、字幕恢复与条目解除关联，再在 IO 线程删除持久文件，遵守 Media3 的播放器线程限制。

大字幕输入省略光标放大镜，保留原生光标手柄、选区、复制粘贴及 IME。Foundation 1.9.4 未提供单字段关闭接口，构建脚本通过 [AGP ASM 接口](https://developer.android.com/reference/tools/gradle-api/8.13/com/android/build/api/instrumentation/AsmClassVisitorFactory) 包装其旧文本框放大镜修饰符；CompositionLocal 只在大字幕关闭，其它编辑器保持原行为。构建桥核对方法签名，升级 Foundation 时须重新检查，不使用运行时反射或全局替换。

## 网页 Cookies

网页启用 Android 原生持久 CookieManager。网页 JavaScript 和拦截的 HTTPS GET 使用同一存储；第一方请求附带 Cookie，响应中的多个 Set-Cookie 和主页面 HTTPS 重定向逐域写回。第三方子资源不附加或保存 Cookie。

“设置 → 网页 → 清除 Cookies”在确认后清除网页登录信息；取消不清除。这个操作不会删除卡片、媒体文件、网页资源目录或插件配置。网络资源仍按原约定存于内容所有者的 Appdata；Cookies 使用系统 WebView 的专用存储。既有 HTTPS GET、来源隔离和插件动作权限边界不变，完整浏览器的 POST 与站点存储兼容仍不在此组件的支持范围。

网页的整卡片安全区以实际 Compose 宽高换算成 CSS 像素。窗口仅高度变化也会更新 `--kigtts-viewport-height`，避免 WebView 容器入场时 `vh` 更新滞后造成背景缺口。

## 入场与退场

条目详情使用普通二级页面，与其它页面共用导航栈、大顶部栏和进入/返回动效；从右侧进入并向同一侧退出，预测返回取消后保留草稿。保存或返回会恢复原快捷文本排序面板。切到 HTML/文本编辑器或页面库时继续保留共有字段，返回和旋转不重新入场。原条目容器变换全屏弹窗已移除。

快捷文本排序面板仍按原设计占满主界面可用区域。条目和分组拾起时震动，实际换位时轻震，放下时反馈；取消拖动不发完成震动。选中的分组 Tab 使用胶囊形状，左右滑动切组后，Tab 栏平滑滚到该分组；正在排序时不抢走拖动和滚动。

竖屏保留收起和单行停靠点，原来的半行紧凑档改为两个完整条目行。从两行起按 88 的条目高度和 4 的行间距逐行吸附，上下操作区合计 96；两行、三行、四行、五行分别为 276、368、460、552。超过屏幕空间的停靠点不生成，能放下两行但放不下三行时最高停在两行，历史高度恢复到最近的可用停靠点。横屏继续按整列吸附；两种方向都在靠近或跨过实际停靠点时震动，不再每隔固定距离震动，吸附点附近小幅抖动不会重复触发。

控件在禁用与可用之间按当前 Material 颜色角色平滑过渡，涵盖动作按钮、开关、滑条、菜单和输入框；真实点击与输入权限仍随状态立即切换。快速反向切换从当前颜色继续，禁用按住的按钮会取消按压。大字幕底部光标移动条在进入输入时淡入并从中间展开，结束输入时淡出收拢；两侧按钮平滑让出或恢复空间，工具栏高度不变，退场期间不再响应触摸或无障碍光标动作。

主界面两张字幕卡片的字号滑条与按钮区以固定高度交叉淡入、水平移入/移出；退场滑条不能抢返回或继续修改字号。横屏拖到收起位置时，胶囊和圆按钮按实际宽度恢复尺寸，插件按钮槽同步收缩，手指尚未释放也可恢复原形。

普通弹窗统一由 `MotionAlertDialog` 管理窗口、遮罩和终止动作。窗体轮廓从中心以横向 90%、纵向 60% 展开并淡入，260 ms 内落定；内容层抵消窗体缩放，文字、图标和按钮始终保持原尺寸，通过淡入淡出显现。大视觉元素可独立形变，取色器的颜色预览使用这一接口。退出 180 ms，内容先退，背景遮罩独立淡出。确认按钮立即提供一次震动，动作仅在退场完成后执行一次；空白区域、返回键和预测返回使用同一路径。取色器、分组、删除、插件输入/菜单和未保存确认共用此组件。异步保存失败保持弹窗可编辑，成功后才退场。

设置的相连按钮组在按下事件到达时立即震动并启动 75 ms 形变；短点击也完成一次可见脉冲。尺寸及原生圆角由同一动画进度控制，连续点击中断旧收尾，释放后恢复。主题圆角切换在 220 ms 内缓动到新档位。

共用图标、胶囊按钮和分组 Tab 在收到按下事件时立即开始原生形变，短点击保留约 75 ms 的可见反馈。滚动接管、取消、连续按压和组件卸载都会清理之前的按压；不会叠加原生延迟 Press 而残留按压形状。点击和长按路由仍由原生控件处理，触感继续服从全局开关。

## 横屏入口

左栏菜单位于上方，自动播放与朗读开关位于下方；横屏抽屉从左展开，关闭和预测返回固定向左。右侧快捷栏折叠时，名片按钮位于上方、画板按钮位于下方，均为 48 的圆形按钮，中间快捷入口为 48 × 160 的竖向胶囊。展开后上下圆形按钮缩为 32，中间胶囊变成可拖拽手柄；插件按钮变化不更换手势所有者。

横屏名片和画板均从右侧进入。各页面记录当次入场侧，旋转、预测返回及取消手势不改向。竖屏延续右侧抽屉和原有页面方向。

## 输入、文字菜单与提示条

条目和独立文本编辑器在输入焦点激活时提前收起大顶栏，输入期间避免嵌套滚动与顶栏动画竞争。IME可见性和顶栏紧凑标题只在状态跨阈值时更新；选区、窗口大小和顶栏动画复用已转换的格式跨度。文本、格式与光标共同保存，撤销和重做同时恢复文字及格式；仅移动选区不增加撤销记录。

Compose文字菜单使用Foundation公开Provider与原生操作回调，复制、剪切、粘贴、选全及格式用图标按钮呈现，提供无障碍标签和长按说明；系统的“朗读”菜单项移除，其它文本处理操作保留。菜单锚定正在编辑的字段并在布局完成后定位，弹窗使用自己的原生窗口坐标。进入和退出只对容器形变，图标保持大小；返回先关闭菜单并收拢选区，保留输入焦点，不允许旧选区因文字重排重开菜单。再次长按仍可正常打开。选全或选区变化时，格式项和回调在同一会话内更新，新增按钮的容器尺寸缓动。基础格式可连续设置，颜色与字号另开选择器。旧插件API8的richText字段继续兼容；原生编辑界面始终启用富文本，不修改未编辑的旧条目。

Snackbar使用当前主题圆角。竖屏快捷文本收起时避让底部工具栏，展开时避让底部Tab，输入时避开键盘；保留的后台主页和横屏不占用竖屏提示条位置。锚点在实际布局阶段读取，拖动面板不引起整页重组。

视频前景与背景的原生TextureView栅格固定为源比例尺寸，不随面板大小改变；Compose仅通过RenderNode等比变换让前景居中适应或填充、背景填充整个卡片，卡片裁切多余边缘。同一个解码帧另经低分辨率GPU高斯处理输出背景，暂停切换填充与适应时也保留背景缓存。拖动不seek、REDRAW或取出缓存后续帧，避免Surface尺寸变化释放排队帧与异步背景留黑边。手动暂停、播放位置和实况自动播放消费状态跨布局与旋转保留，再次选取内容重建播放会话。帧池仅在源视频尺寸改变时配置；没有第二个解码器、逐帧CPU读回或Media3内部管线依赖。
