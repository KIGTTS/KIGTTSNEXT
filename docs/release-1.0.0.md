# 1.0.0 发布准备

收到明确的正式上线指令前，KIGTTS、官方插件、资源包和模板的版本固定为 `1.0.0`，构建号固定为 `10000`，插件 API 固定为 `1`。准备包在本地打包和验证。正式发布时再创建对应标签、上传 APK 和各包，并一起切换市场目录。

后续变更继续向下兼容。更新接口和数据格式时，验证旧插件、资源包、备份和已有安装数据仍能正常加载，并为需要转换的数据保留迁移路径。

## Android 安装

正式包沿用 `com.lhtstudio.kigtts.app`。发布签名脚本会核对旧版证书指纹并验证签名后的 APK。官方插件的签名清单署名为 KIGTTS，继续使用原有的发布者密钥。

```powershell
./tools/Build-OfficialRelease.ps1 -SigningBackup <本地正式签名备份>
```

开发调试可用 `-PkigttsPreviewPackage=true` 构建 `com.kigtts.next`。Android 按包名区分这两套安装，正式包直接更新同包名的旧版，预览测试数据可通过备份迁移。

## 升级和资源

- 同包名旧版本的首次升级会读取原数据，再显示升级欢迎页。权限和预设快捷文本页从升级流程略过。
- 来自旧版的音效和快捷文本进入快捷文本库，名片进入扩列收藏夹。悬浮窗第三方入口按原组件名称迁移。
- Piper 语音包可以在安装引擎前保留。缺少引擎时会提示打开对应下载入口。旧 Kokoro 文件留在源数据中。
- 已签名的预览 API 9–38 插件和预览 API 29–38 资源仍可加载。新资源按 API 1 打包。

## 拓展市场

发行清单只列独立分发的插件。AI 助手、插件编辑器、原生构建、拓展市场、朗读、识别和手势已由主程序提供。与内置功能有关的源码保留给宿主构建。

市场目录引用的每个包都需要真实的版本、大小、签名者指纹和 SHA-256。资源包可以独立重建，历史发布目录与兼容包保留其原始文件。

正式发布时同时上传 SDK 1 的 Java 与 Kotlin 二合一工具链，并更新编辑器的下载地址与校验值。
