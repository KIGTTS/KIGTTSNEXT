# 全屏画板与作品相册

画板属于主程序内建功能。画布覆盖整页和透明顶部操作区，进入时隐藏系统栏，离开或打开作品相册时恢复。仅按钮和工具栏避让刘海、挖孔及系统安全区，空白顶部仍可绘画；返回键使用无底色图标。竖屏工具栏位于底部，横屏位于右侧；工具顺序为笔、橡皮擦、当前颜色、保存和清空。颜色按钮直接打开共享 HSV 取色器。

画布可双指持续平移、缩放，笔迹可以延伸到首次画幅之外和负坐标区域。首次尺寸仅用作笔迹坐标及笔宽的参考，旋转只改变视口，不清空或改写笔迹。双指操作不生成笔迹；第二指接入时撤销当前未完成的一笔。压感、手写笔侧键及临时橡皮擦由统一输入控制器处理，「显示全部笔迹」自动对齐完整笔迹及其留白。

顶部更多菜单的「画布背景」提供纯色、方格本和点阵。背景锚定画布坐标，随平移和缩放变化，缩小时自动降低密度以保持流畅。背景样式与作品、草稿一起保存，也保留在导出图片中。文档格式版本 2 支持无界坐标及背景样式，并兼容版本 1 的已有作品。

作品保存在 `appdata/Kigtts/sketch/works/<id>/`，包含 `drawing.json`、`image.png` 和 `work.json`。保存也通过 MediaStore 发布 PNG 到系统相册；任何一步失败会回滚本次新增资源。Android 10 及以上采用 pending 图片写入，Android 8／9 按需申请系统相册写入权限。作品列表按保存时间从新到旧排列，重新打开恢复完整可编辑笔迹。保存和分享按全部笔迹（包含完整笔宽）的范围取图，并自动增加保护区，不受当前视口限制；远处单独的橡皮擦轨迹不会扩大取图范围。局部擦除仍保留原笔迹的保守范围，整笔擦除则移除该笔迹。空白作品保留参考画幅。PNG 最长边限制为 2400 像素，矢量文档保留完整坐标。

自动草稿位于 `appdata/Kigtts/sketch/draft.json`，写入先验证并同步临时文件，再在同目录原子替换；兼容之前遗留的备份文件。分享使用独立 PNG 副本，不修改作品或系统相册原图。

桌面回归覆盖方向和视口数学、双指输入、压感、横竖工具布局、重复草稿替换、保存失败回滚和重新打开笔迹。真实手写笔侧键、系统相册展示与绘制流畅度仍需设备检查，结果记录在 [Release 验证](release-testing.md)。
