# 全屏画板与作品相册

画板属于主程序内建功能。画布覆盖整页和透明顶部操作区，进入时隐藏系统栏，离开或打开作品相册时恢复。竖屏工具栏位于底部，横屏位于右侧；工具顺序为笔、橡皮擦、当前颜色、保存和清空。颜色按钮直接打开共享 HSV 取色器。

笔迹使用首次创建画布时的尺寸和归一化坐标保存，旋转屏幕只改变视口，不清空或改写画布方向。双指缩放和平移不生成笔迹；第二指接入时撤销当前未完成的一笔。压感、手写笔侧键及临时橡皮擦由统一输入控制器处理，恢复视图按钮可回到完整画布。

作品保存在 `appdata/Kigtts/sketch/works/<id>/`，包含 `drawing.json`、`image.png` 和 `work.json`。保存也通过 MediaStore 发布 PNG 到系统相册；任何一步失败会回滚本次新增资源。Android 10 及以上采用 pending 图片写入，Android 8／9 按需申请系统相册写入权限。作品列表按保存时间从新到旧排列，重新打开恢复完整可编辑笔迹。导出图最长边限制为 2400 像素，矢量文件保留原始画布尺寸。

自动草稿位于 `appdata/Kigtts/sketch/draft.json`，写入先验证并同步临时文件，再在同目录原子替换；兼容之前遗留的备份文件。分享使用独立 PNG 副本，不修改作品或系统相册原图。

桌面回归覆盖方向和视口数学、双指输入、压感、横竖工具布局、重复草稿替换、保存失败回滚和重新打开笔迹。真实手写笔侧键、系统相册展示与绘制流畅度仍需设备检查，结果记录在 [Release 验证](release-testing.md)。
