# 字幕空白提示

启动时真实正文是空字符串。默认的「点击输入文字」只是显示提示，可在设置 → 外观 → 字幕 → 空白提示中修改；允许多行、最多 200 个 Unicode 字符，也可留空以隐藏。保存与取消使用原生动效对话框，取消不修改设置。

新进程启动固定进入主页面，不自动打开上次的媒体、网页快捷文本或编辑页；保留已保存的词条、媒体和外观设置。旋转屏幕沿用当前 ViewModel，继续保留当前页面、内容及未结束的编辑。显式打开的添加源链接继续按正常流程处理。

显示与输入状态都使用独立的占位层，不把提示写入 `TextFieldValue`。提示独立计算显示字号，不参与正文的富文本格式、朗读、导出或语音识别拼接。输入真实文字后自动消失；正文再次为空时按设置恢复。

空白提示遵循大字幕的字号设置（单字占屏幕宽度的百分比），双指缩放或调整字号栏时同步变化。短提示按首选字号显示；多行或长提示在面板空间不足时复用大字幕的自适应计算，暂时缩小，面板展开后恢复首选字号，不改写保存的百分比。自适应不会低于原有的 24sp 可读下限；用户首选字号本身更小时则尊重该设置，达到下限后不再继续缩小。

快捷文本上屏只淡入淡出；重复呈现相同正文不重启动效。输入时文字平滑让位，迁行使用短距离水平淡出/淡入，完整行增减平滑移动。视口缩小或增大时均立即重新计算字号，光标同步跟随排版；文字不用弹簧动效。

设置 → 外观 → 字幕动效可开启「减弱字幕动效」，只保留清屏、快捷文本上屏和占位提示的淡入淡出。「展示时换行动效」独立控制非输入状态下调整字号或面板大小的重排；减弱模式启用时暂时关闭，退出减弱模式后恢复原选择。

`SubtitlePlaceholderStore` 在 `appearance` 偏好的 `subtitlePlaceholder` 键保存用户自定义文本；空字符串与尚未设置有不同含义。存储类允许调用者注入本地化默认文本，未自定义时使用当前语言默认值，用户自定义文本不会随语言切换被覆盖。标准化会移除 NUL、统一换行，并按 Unicode codepoint 截断，避免切开 emoji 的代理对。

占位文本在展示状态与正文使用相同的换行动效，同样遵循减弱动效和展示换行开关；进入输入状态保留透明度渐变。
